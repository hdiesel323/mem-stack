# Unified Memory Stack Instructions

This project uses the Unified Memory Stack for persistent context across sessions.

## Memory Systems Available

| System | Use For | Query Method |
|--------|---------|--------------|
| **Beads** | Current tasks, dependencies | `bd ready`, `bd show <id>` |
| **Memvid** | Past decisions, learnings | `memory:search_knowledge` |
| **Claude-Mem** | Session observations | `memory:get_recent` |
| **Cartographer** | Codebase structure | `memory:query_codebase` |

## Session Workflow

### Starting Work

1. Check ready tasks: `bd ready`
2. Query relevant context: `memory:query "<topic>"`
3. Claim a task: `bd update <id> --status in-progress`

### During Work

- **Where is X?** → Query Cartographer or grep codebase
- **Why did we choose X?** → `memory:search_knowledge "X decision"`
- **What was I doing?** → `memory:get_recent`
- **Found new work?** → `bd create --discovered-from <current-task>`

### Completing Work

1. Close task: `bd close <id> --summary "..."`
2. Log decisions: `memory:log_decision` for significant choices
3. End session: `memory:end_session` (auto-persists learnings)

## Query Routing

The `memory:query` tool auto-routes based on question type:

- "Where is authentication?" → Cartographer (codebase)
- "What tasks are ready?" → Beads (tasks)
- "What did I do earlier?" → Claude-Mem (session)
- "Why did we use Postgres?" → Memvid (knowledge)

## Task Management with Beads

```bash
# View ready tasks
bd ready

# Create task with dependencies
bd create "Fix auth bug" --blocks bd-xyz

# Work discovery pattern
bd create "Add validation" --discovered-from bd-abc

# Complete with summary
bd close bd-abc --summary "Implemented OAuth2 flow with refresh tokens"
```

## Recording Decisions

Use `memory:log_decision` for significant architectural choices:

```json
{
  "topic": "database-choice",
  "decision": "PostgreSQL",
  "rationale": "Need ACID transactions for financial data",
  "alternatives_considered": ["MongoDB", "SQLite"]
}
```

## File Locations

```
.beads/          # Task graph (git-tracked via beads.jsonl)
.memvid/         # Long-term knowledge
.claude-mem/     # Session observations (gitignored)
docs/CODEBASE_MAP.md  # Cartographer output
.mcp/            # MCP server scripts
```

## Best Practices

- Start sessions with `memory:start_session` to load context
- Query Memvid before re-making past decisions
- Use `--discovered-from` to link related tasks
- Log significant decisions immediately
- End sessions properly to persist learnings

## Common Commands

```bash
bd ready              # What can I work on?
bd show bd-xxx        # Task details
bd create "..."       # New task
bd close bd-xxx       # Complete task
bd sync               # Push to git
/cartographer         # Map codebase
specstory run claude  # Launch with history
```
